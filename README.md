# Normal Day as a Data Analyst

A short, meme-inspired browser game about getting the weekly trading report to the Trading team before the morning meeting. Play as CJ and make choices about source weeks, duplicate rows, and retail KPIs as the dashboard crisis unfolds.

## Play locally

1. Clone or download this repository and keep `index.html` beside the four JPG scene images.
2. Open `index.html` in your browser. The game runs locally without installing anything or starting a server.
3. Select **GET UP, CJ**, then click or tap an action in each scene.

Your choices affect your final score. Select **Start over** to replay the day and try different decisions.
